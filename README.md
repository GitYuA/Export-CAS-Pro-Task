#  Export CAS Pro Task Tampermonkey Script

用于 CAS Pro 的任务导出脚本。脚本会自动识别页面中的任务卡片，提取任务名称，并支持按目录层级分类导出为 TXT 文件，也可以按需附带完整目录和任务链接。

## 文件

- ` Export CAS Pro Taskr.js`：Tampermonkey 用户脚本

## 功能

- 导出当前页面任务卡片中的任务名称
- 按目录路径分类，例如 `影视/动漫`
- 可配置分类层级
- 可选择是否去重
- 可选择是否导出链接
- 可选择是否导出完整目录
- 面板显示当前页面可导出的任务数量
- 导出文件包含总任务数和每个分类的任务数
- 自动下载为 `.txt` 文件

## 安装

1. 打开 Tampermonkey。
2. 新建脚本。
3. 将 `export-span-text.user.js` 的内容复制进去。
4. 保存脚本。
5. 刷新目标网页。

脚本会在识别到 CAS Pro 任务卡片后，在页面右下角显示导出面板。

## 面板选项

### 去重

默认不勾选。

勾选后，同一分类下相同的任务内容只导出一次。

### 链接

默认不勾选。

勾选后，会在任务下面额外导出任务链接。

### 目录

默认不勾选。

勾选后，会在任务下面额外导出完整目录路径。

### 分类层级

默认值是 `2`。

示例目录：

```txt
影视/动漫/标题 (2026)/Season 01
```

不同分类层级效果：

```txt
1 => 影视
2 => 影视/动漫
3 => 影视/动漫/标题 (2026)
4 => 影视/动漫/标题 (2026)/Season 01
```

### 任务数量

面板中的 `任务` 会显示当前页面可识别的任务数量。

导出文件顶部会显示总数，每个分类标题后面会显示该分类的任务数量。

## 输出示例

只导出任务：

```txt
任务总数: 2

[影视/动漫] (任务数量：2)
标题 (2026)
标题标题 (2024)
```

勾选 `目录` 和 `链接` 后：

```txt
任务总数: 2

[影视/动漫] (任务数量：2)
标题 (2026)
目录: 影视/动漫/标题 (2026)/Season 01
链接: https://cloud.189.cn/t/123456789
标题标题 (2024)
目录: 影视/动漫/标题标题 (2024)/Season 01
链接: https://cloud.189.cn/t/987654321
```

## 限制

- 只导出当前页面已经加载出来的任务。
